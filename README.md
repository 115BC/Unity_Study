# 《60秒·空难荒岛》(60slike)

27 学年秋季虚拟现实课程项目 | Unity 2022.3.62f3 LTS | PC(键盘 + 鼠标)

## 这是什么

一款卡通渲染的空难荒岛生存游戏。飞机失事前 **45 秒**的机舱拾荒(带什么、救谁),跳伞落岛后 **50 天**的荒岛生存(饱食 / 水分 / 体力 / 队友精神),7 种明面结局之外还有一条「暗影的账本」暗线真结局。名字里的"60 秒"是品牌不是时长 —— 核心体验是**取舍**:舱里多贪一格、岛上多信一夜人。

## 跑起来

1. 用 Unity Hub 安装 **2022.3.62f3 LTS**,以 Unity 打开本仓库根目录
2. 打开 `Assets/Scenes/Demo.unity`,直接 Play
3. 标题屏五颗按钮:**登上飞机 / 收集 / 设置 / 致谢 / 退出游戏**;开局姓名在设置页填(会出现在铭牌、合影与结局字幕上,不超过 8 字)

## 操作

| 阶段 | 键位 |
|---|---|
| 拾荒(机舱 45 秒 = 15 查看 + 30 拾取) | WASD 移动 · 鼠标转视野 · 左键锁定/放开光标 · E 拾取与使用 · Q 在舱门投递入箱 |
| 跳伞 | Q(舱门区域内)直接落岛 |
| 荒岛(白天) | 鼠标点选物体 · E 走近交互 · V 固定/自由视角 · 左 Shift 奔跑(自由视角)· Tab 行动面板 |
| 任意(开始游戏后) | **Esc = 暂停菜单**(继续游戏 / 设置 / 退出游戏),游戏自动暂停 |

设置页顶部「**画面 / 声音**」两个子页:画面 = 全屏 / 窗口 / 窗口(无边框)、帧率上限(30/60/120/144/不限)、分辨率(5 档全 16:9);音效 = 主音量(所有声音)、BGM 音量(拾荒与生存阶段)。四项全部 PlayerPrefs 跨局记忆,启动自动套用。

## 工程结构

- `Assets/Scripts/Core/` —— 阶段状态机(GameRoot / RunState)、数据(SO:物品 / 事件 / 配方 / 结局)、UI 工具(UiKit,代码织 UI)、设置与暂停(SettingsPage / PauseMenu)、各结局过场
- `Assets/Scripts/Phases/` —— 四个阶段:Title / Scavenging(机舱 45 秒)/ Island(荒岛 + 夜晚结算)/ Ending
- `Assets/Scripts/Editor/` —— 开发者菜单 `Tools/60slike/*` 与离线自检 `DemoChecks`
- UI 全部由代码织成(场景里没有 UI 资产);内容全部数据驱动(SO),加事件不改调度代码
- 存档 = PlayerPrefs(`SaveData`):姓名、日期格式、画面/音量设置、真结局标记等

## 开发者菜单(Tools/60slike)

| 菜单 | 作用 |
|---|---|
| ① 生成数据资产 | SO 数据表 → 资产(已有的不覆盖) |
| ② 生成 Demo 场景 | 场景 + 机舱灰盒(已有的不覆盖) |
| ③ 强制重建全部资产 | 丢弃 Inspector / Scene 改动,全量重建 |
| ④ 只重建荒岛层 | 不动机舱与其它改动 |
| ⑤ 打印模型尺寸 | 排查缩放 |
| ⑥ 生成物品栏缩略图 | 携带条每格小贴图 |
| 运行自检 | DemoChecks 全量断言(数值 / 坐标 / 文案 / 接线) |
| Play 冒烟 | 自动跑一局 |

⚠ **⑥ 会离屏渲染覆盖整个 `Assets/Resources/Icons/`** —— 队友头像与 17 件物品图标是手绘替换的,会被冲掉;除非要重生成默认图标,否则别跑。改了事件 / 选项文案要跑 ① 才刷进资产。
